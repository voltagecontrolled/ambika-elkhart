# ambika-elkhart v4.4

A full pass over the synth voice and the sequencer/UI surface. The voice gains a second per-voice LFO (LFO 5), MIDI-clock-synced rates and one-shot envelope-style shapes for both voice LFOs, a pre-filter wavefolder, an sn16 windowed sine bank that replaces the unused CZ filter-sim shapes, an FM family clustered in the oscillator scroll wheel (`fm`, `fmfb`, `fmca`–`fmce`), and two 4-partial additive percussion shapes (`hrm1`, `hrm2`). The sequencer's lock surface gets unified: every patch-page cell is per-step lockable, intrinsic per-step storage collapses into the same pool every other lockable uses, and gestures that used to live only on the Step page (peek, double-tap-clear, drill-in PROB) now work on every page where you can set a lock. The mod matrix is retired in favor of four hardcoded direct routings (everything `kDefaultMod` actually wired), groovebox MIDI handling is trimmed to what the use case needs, and the EXT-track MIDI CC editor moves to a dedicated page reachable only when the track is EXT.

## Voice

- **Second per-voice LFO — LFO 5.** Full clone of LFO 4 (own shape / rate / retrigger byte, own mod-matrix slot, own UI cell row on the Voice LFO page). Dest and amount configurable per patch. Doubles the per-voice modulation surface.
- **MIDI-clock-synced rates for both voice LFOs (#12).** Rate field is two-zone: `0..14` indexes 15 sync ratios (`1/96`..`1/1`), `15..142` is the existing free-run range. Synced LFOs render through the same per-block advance path used by free-run — no stepping, no per-tick jitter. Synced rates stay frozen until the first MIDI tick after transport start so phase is deliberate. Transport double-stop broadcasts a new `COMMAND_LFO_RESET` so synced LFOs can be aligned to song position.
- **One-shot LFO shapes — `1exp` / `1lin` / `1tri`.** Fire once on retrigger then hold at zero. Backed by the existing envelope LUT for the exponential shape, computed inline for the linear and triangle shapes. With LFO 5 routable anywhere, this gives a fourth "envelope" without paying for a fourth envelope generator.
- **Pre-filter wavefolder — `FOLD` on `S2` (#18).** New cell on the Filter page top-row gap. Iterative reflection between the sub-osc mix and the noise/fuzz stage; signal scales by drive then bounces excursions past ±128 back into range. Drive ranges ~1.06× to ~16.9× across 254 distinct values (no integer stepping). Per-step lockable, mod-matrix routable (`MOD_DST_MIX_FOLD`), responds to inbound CC#90 and NRPN 111.
- **sn16 windowed sine bank.** Replaces 9 unused CZ filter-sim shapes (`CZ_SAW_LP..CZ_TRI_LP`, formerly slots 6..14) with a single `WAVEFORM_SIN_16BIT` at slot 6. `PARA1` steps through 8 sine variants: full, half-rectified, abs / full-rectified, quarter, alternating, camel, square, log-saw. Stepped (not crossfaded — crossfading produced pitch-sensitive aliasing beating on high notes).
- **FM family clustered — `fmfb` + `fmca` / `fmcb` / `fmcc` / `fmcd` / `fmce` (#34).** Five new sin16-carrier 2-op PM shapes appended next to the existing `fm` and `fmfb` in the scroll wheel. Each pair (`fm`, `fmfb`, `fmca..fmce`) modulates a different shaped sine carrier from the sn16 bank. Per-osc 2-op PM combined through the existing mixer gives 4 operators per voice — closer to how OPL/OPN stack operators.
- **HRM additive percussion — `hrm1` / `hrm2`.** Two 4-partial additive shapes. `RANGE` drives partial spread bidirectionally: harmonic series at centre, octave stack CW, sub-octave stack CCW. `hrm1` PARA detunes partials for chorus/swarm; `hrm2` PARA cascades partial-to-partial PM for bell/clang. Folds beautifully through the new wavefolder. **Known limitation:** audio degrades when paired with another shape on the same voice — use solo per voice.
- **Patch compat break for shapes ≥ slot 6.** Patches that used QUAD_SAW_PAD, FM, vowel, wavetable, etc. need their osc shape re-selected after upgrade. Slots 0..5 (NONE, POLYBLEP_SAW, POLYBLEP_PWM, TRIANGLE, SINE, CZ_SAW) are unchanged. Chained snapshot migration handles existing v4.3 snapshots automatically; values land at their new enum positions on load.

## Sequencer + UI

- **Patch pages are the canonical lock-write surface (#41).** Every patch-page cell on OSC / MIXER / FILTER / ENV / LFO is now per-step lockable. Hold a step button while turning any patch-page pot to write a per-step lock for that parameter. The `kNumLockableParams` namespace grows from 28 to 48; new slots cover everything that has a per-fire-time DSP byte (osc rang, xmod / fuzz / crsh, filter reso / mode, full E1 / E2 / E3 envelope shapes, all eight LFO 4/5 controls).
- **Intrinsic locks unified into the lock pool (#45).** The NOTE / PROB / SSUB / REPT / VEL / GLID intrinsics used to have dedicated per-step byte storage separate from the lock pool — adjusting a track default would broadcast over locked steps and silently wipe them. They now live in the same pool every other lockable uses. Track defaults seed unlocked steps at fire time; locked steps stay pinned to their pool value. `SeqStep` shrinks from 7 B to 2 B; lock pool capacity grows from 192 to 240 entries.
- **Per-lock PROB drill-in everywhere (#41).** Drill-in gesture (cursor on a lockable cell, hold step, click encoder) flips the cell into PROB-edit mode — the pot now writes a bipolar PROB byte attached to that lock instead of the lock value. Cells with a non-default PROB render their label `UPPERCASE` as a "this lock is gated" indicator. Works on every patch page, the Step page, the new MIDI CC page, and the substep editor's SUBS PROB cell.
- **Encoder long-press clears every lock for one parameter on the active track (#42).** Hold the encoder click for ≥ 800 ms with no step button pressed while the cursor is on a lockable cell — every step's value lock + PROB entry for that parameter is wiped, with a brief `clr locks` cell overlay as feedback.
- **Cross-page step-button gestures.** Hold-to-peek (≥ 250 ms skips the toggle on release; lets you inspect a step's locks on any page) and double-tap-to-clear (two short taps within 300 ms wipe every per-step lock for that step) now work on every page that inherits the default OnKey — previously these were S5a-only.
- **Sequencer locks group collapses to a single Step page (S5a) (#32).** The retired S5b ("Voice 1: osc/mix") and S5c ("Voice 2: filter/env/sub") were duplicating cells the patch pages already own. Encoder turn on S5 no longer paginates — it walks the 8 S5a cells and spills to the neighboring groups.
- **Dedicated EXT MIDI CC page (#32).** When the active track's `mmod` is EXT, `S1` / `S2` / `S3` / `S4` + encoder all route to a single 4-slot CC editing page in place of the synth pages. Each slot has its own per-slot enable bit (default off — fresh EXT tracks emit no CC until you opt each slot in). Encoder click on a cell toggles enable. Pots 0..3 dial CC# without arming the slot so you can configure CC numbers safely with the sequencer running; pots 4..7 dial the CC value with live MIDI emit when the slot is enabled. Held step + value pot writes a per-step lock on the CC value through the same lock pool every other lockable uses.
- **Page-mode hard gate (#32).** Synth pages are unreachable on EXT tracks; the MIDI CC page is unreachable on INT tracks. Encoder spill across page boundaries, S1 / S2 / S3 / S4 group jumps, and active-part changes all route through the gate — you can't accidentally end up editing patch params on an EXT track or staring at the CC editor on an INT track.
- **Combined MCH + MMOD cell on S6a (#32).** Cell 6 hosts both the MIDI channel and the INT / EXT mode toggle on a single cell. Encoder click swaps which subparam the pot edits — label flips between `mch` and `mmod`. Frees the adjacent cell for the new init action.
- **`init` action on S6a (#32 / #25).** Cell 7 hosts a per-track init gesture. Pot selects between `voic` (reset the track's patch defaults from the factory init values; voicecard is touched immediately) and `ploc` (clear every per-step lock + per-lock PROB on this track). Encoder long-press (≥ 800 ms) executes; LED 6 rapid-flashes red for ~600 ms as acknowledgement. Both modes preserve the step pattern, the intrinsic per-step state, and the track-level sequencer config — `init voic` keeps your locks, `init ploc` keeps your knob settings.

## Filter / envelopes / LFO page reorg

- Filter envelope moves off the Env page onto the Filter page bottom row (E2 rise / fall / curv / depth). The redundant `FILTER1_ENV` cell that used to sit on the Filter page top row is dropped.
- Pitch envelope (E3) takes the freed Env page bottom row (E1 still on top).
- Voice LFO page becomes two rows: LFO 4 on top, LFO 5 on bottom, each `rate | wave | dest | dept`.
- New navigation shortcut: **Hold-S3 + turn encoder** jumps to the Oscillators page from anywhere; from any synth page, it cycles OSC → MIXER → FILTER → ENV/LFO → VOICE_LFO.
- WS0 layout shifts (#46): boot page changes from Filter to Sequencer. OSC1 TUNE soft-dropped from the UI; the freed osc-page cell takes MIX (moved off the XMOD/Mixer page). FOLD moves into the XMOD/Mixer cell vacated by MIX. Filter defaults shift to a neutral "off" filter on init (cutoff fully open, Env 2 depth = 0).

## Mod matrix retirement + groovebox MIDI trim

- **Mod matrix retired.** The 14-slot `ProcessModulationMatrix()` is replaced with four hardcoded direct paths covering the only routings that ever carried a live amount through `kDefaultMod`: LFO 5 → user dest, LFO 4 → user dest, ENV 1 → VCA (with E1DEPT amount), VELOCITY → VCA. The mod matrix UI page was already retired in v4.2. `kDefaultMod` table and its 42-byte ship loop on the controller deleted. Patch struct preserves the `modulation[14]` + `modifier[4]` bytes as anonymous padding to avoid a snapshot version bump.
- **Pitch bend / mod wheel / aftertouch handlers removed.** Elkhart's design centre is groovebox, not synth module — incoming MIDI PB / CC1 / channel pressure / key pressure no longer drive any synth state. MIDI Thru / Chain / Full passthrough unaffected.
- **Parameter table shift (#47).** Eight orphan `parameters[]` entries from the retired mod matrix removed; subsequent IDs shift down by 8. `kParamLockMap[]`, `midi_cc_map[]`, `midi_nrpn_map[]`, and `page_registry[]` all updated. MIDI surface additions from this pass: FOLD now responds to inbound CC#90 and NRPN 111 (was unmapped on both).

## Other fixes

- **System page survives a missing SD card (#39).** Probe once on entry, cache the result. When absent: slot indicator renders `?` instead of `*`, save/load LEDs go dark, attempts early-exit with red-blink feedback. Previously the page would lock up the display refresh during the no-card mount timeout. BPM and CLK pots remain fully responsive — tempo tweaks no longer pay a card-related cost during live use.
- **Iterative PROB double-count fix on forward jumps.** A `jmp` SMOD that landed on or past the current step would bump the loop counter twice per cycle — once manually after the jump, once via the natural-wrap bump. Symptom: an iterative PROB on a forward-jmp step would fire on the expected cycle then drift. The manual bump now runs only when the jump direction would actually prevent the natural wrap.
- **Double-tap clear now wipes SMOD + substep_bits (#40).** Previously left the step's SMOD nibble and ratchet pattern intact — a step's `JMP3` or its ratchet pattern would silently survive the gesture meant to zero the step.
- **WAV1 / WAV2 lock pot mapping fix.** The seq-steps lock pot was applying a `+9` offset that skipped the (now-removed) CZ slots, producing shape values past `WAVEFORM_LAST` and crashing the voicecard.

## Storage

- **Snapshot file format v0x0b.** Chained migration loads every snapshot from v0x01 onward. v0x0a → v0x0b is byte-layout-only (MIDI CC region reinterpretation per #32) — on load, all CC slots come up disabled with default values. Reconfigure your EXT-track CC slots once and re-save.
- **EEPROM-persisted track state overrides the new init defaults on existing rigs** — see future factory-reset work for the wipe path. The S6a `init voic` action covers per-track reset.

## What didn't make v4.4

- **Groove-template surface cleanup (#49).** Dead since the transport-page `swng` removal — `MultiData.clock_groove_template` / `clock_groove_amount`, the `kGrooveTemplate` LUT, the SWING / SHUFFLE / MONKEY strings, and the `UNIT_GROOVE_TEMPLATE` enum slot are all standing. Mechanical removal deferred to v4.5 to avoid changing parameter-table indices late in the v4.4 cycle.
- **Substep editor rename.** The SUBS click editor now hosts more than ratchets / repeats (chord walk per loop wrap, per-#36 loop-wrap chord walk) — a clearer page name is on the v4.5 docket.

## Resource usage

- **Controller:** 90.4% → 91.4% flash (`+1024 B` over v4.3); 81.6% → 82.1% RAM (`+24 B`).
- **Voicecard:** 81.2% (`+381 B` over v4.3, driven by the new oscillator family and the wavefolder DSP).
- **Lock pool capacity:** 192 → 240 entries (5 B/step saved from `SeqStep` shrink funded 48 extra pool slots with 96 B left over as net RAM).
